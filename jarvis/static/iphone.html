Ilaria sul iPhone

Una volta sola. Poi il microfono funziona.

  1. Scarica il profilo e aprilo.
    Scarica profilo Ilaria
  2. Impostazioni → Profilo scaricato → Installa.
  3. Impostazioni → Generali → Info → Attendibilità certificati → attiva Ilaria.
  4. Apri Ilaria in Safari:
    Apri Ilaria

Stesso Wi‑Fi di casa. Il computer deve restare acceso.
